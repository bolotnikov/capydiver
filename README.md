# CapyDiver: Sunken Gardens

Playable web distribution, version 0.1.1. Game source is maintained separately.

- [Play on GameDev.Land](https://gamedev.land/games/capydiver/)
- [Standalone build](https://bolotnikov.github.io/capydiver/)

Use WASD or the arrow keys to swim. Press Space or click to dash. On a touch screen, use the floating joystick and the Dash button.
